# 今日计划

一个紧凑的 Windows 桌面日清单。开机自动展开，默认置顶，右键管理。

## 打开与使用

双击本目录的 **我的计划.lnk**，或运行 **app\\DesktopTodo.exe**。无需另装 .NET。

- 默认只显示当天任务，跨天自动切换；以前未完成的任务放在“待补办”。
- 任务按 1、2、3……编号，无分类、无分组。
- 右键标题或空白处：新增任务、选择其他日期、返回今天、设置、置顶、收起、退出。
- 右键任务：编辑、修改日期、上移、下移、删除；已完成任务可恢复未完成。
- 向右拖动任务超过行宽 60%（至少 140 DIP）后松手完成；短滑回弹，单击不改变状态。
- 仅顶部空白区域拖动整个窗口；任务滑动不移动窗口。
- 编辑时 Enter 保存、Esc 取消；失焦自动保存有效内容并保留编辑框。
- 展开“高级选项”可设置截止时间和到时提醒。清空截止日期即可取消时间。
- 普通关闭操作收进托盘，后台仍提醒；“退出”结束进程，下次登录仍自动展开。

窗口默认宽 340 DIP，高度随任务内容收紧，空清单约 92 DIP 高。任务过多时限制高度并滚动。任务采用蓝、紫、青绿、暖黄的浅色区分；临近截止的时间为暖色，逾期为红色。滑动达到完成阈值时背景变绿。

## 数据与更新

- data/todo.db：正式数据。
- data/backups：每天首次启动备份，保留最近 7 份。
- data/error.log：错误发生时记录。
- artifacts：隔离的测试数据、渲染图片和验收报告，不混入正式清单。

现有任务内容、日期和完成状态保留。旧版分组信息不再参与界面展示和排序，也不再提供分组操作。

开机启动入口指向项目中的 app/DesktopTodo.exe。移动项目后手动运行一次可更新入口。更新程序时保留 data 目录；关机、睡眠或退出期间不唤醒电脑，恢复后补提醒。

## 开发

C# / .NET 10 / WPF / SQLite，本地单进程，无云端服务。工具与依赖缓存位于 .tools，不修改全局 PATH。

```powershell
.\setup-sdk.ps1  # 仅缺少项目 SDK 时需要
.\build.ps1      # 核心检查并发布 Windows x64 自包含程序
```

构建前退出本应用。源代码位于 src，自动检查位于 tests。

```powershell
.\app\DesktopTodo.exe --data-dir "$PWD\artifacts\preview" --qa-seed
.\app\DesktopTodo.exe --data-dir "$PWD\artifacts\verification" --qa-seed --verify-ui
```

指定 --data-dir 会禁用启动项修改。--qa-seed 仅在空的隔离数据库中创建示例。--verify-ui 输出多比例渲染与检查报告后退出。

## 编辑整月计划

右键桌面窗口，选择 **编辑全部计划**。这个窗口集中编辑整个月，桌面小窗口仍只显示当天。

- **月计划**：写本月整体目标。
- **日期／任务表**：每一天都有可填写的位置；直接在任务列连续编辑。
- **添加任务**：给选中日期增加一条任务，同一天可以写多条。
- **上月／下月／本月**：切换月份；切换不会丢失未保存的内容。
- **保存全部**：一次保存所有已编辑月份的月计划与任务。取消或关闭时会询问是否保存。
- **粘贴多日计划**：日期独占一行，下面每行一项任务；支持跨月和跨年。

例如：

```text
2026-11-01
1. 整理资料
2. 核对实验记录

2026-11-02
1. 完成图表

2026-11-03
1. 写第一版说明
```

也支持“11月1日”“明天”“后天”等日期标题；月日格式使用当前编辑年份。“粘贴”将内容加入草稿，点击“保存全部”后才写入数据库。

修改某项任务的提醒，可在总编辑表中选中该行后右键“高级选项”。已有完成状态、截止时间和已提醒记录会保留。移除原有任务时，保存前会确认删除数量。

界面采用本机已有的 Noto Sans SC（思源黑体），日期、数字和任务正文加粗，序号不带点。

桌面清单不显示任务栏按钮，仅保留桌面窗口与系统托盘图标。到期提示音为 1.9 秒的柔和三音风铃，播放一次并自然淡出。

## 终端启动与拖动排序

在新开的 PowerShell 或 CMD 中输入 `todo`，可从任意目录打开清单；已运行时会唤回原窗口。若终端仍使用旧环境，请完全关闭终端后重新打开。命令入口位于 bin/todo.cmd，已加入当前用户 PATH。

按住整条任务任意位置上下拖动，可在同一天、同一完成状态内插入排序；有插入提示、平滑让位和落位动画。起手方向锁定，上下排序不会触发右滑完成。Esc、失焦或丢失鼠标捕获会取消排序。
