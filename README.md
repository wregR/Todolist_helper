# Todolist_helper

今日计划 · DesktopTodo

**中文** | [English](README.en.md)

把当天要做的事留在桌面上。用紧凑小窗口执行今天的任务，用独立的总编辑窗口提前安排整个月。

当前版本：**0.1.0**。面向 **Windows 11 x64**，采用 [MIT 许可证](LICENSE)。

## 功能

- **桌面常驻**：默认置顶、登录后自动展开，不占任务栏，通过系统托盘管理。
- **当天清单**：只显示当天任务，跨天自动更新，旧的未完成任务进入“待补办”。
- **整条拖动**：上下拖动插入排序，向右滑动完成；方向锁定，避免排序时误完成。
- **整月规划**：月计划、每日任务表、跨月草稿，以及带日期文本的批量粘贴。
- **到点提醒**：任务可选截止时间与提醒，柔和提示音；恢复运行后补发未处理的到期提醒。
- **本地保存**：SQLite 数据库、每日备份，无账号、云同步或应用内遥测。

## 安装与首次运行

1. 从 [GitHub Releases](https://github.com/wregR/Todolist_helper/releases/latest) 获取 Windows x64 ZIP。
2. 如提供 `.sha256` 文件，可使用 `Get-FileHash <文件名.zip> -Algorithm SHA256` 核对。
3. 将 ZIP 解压到当前用户可写的固定目录，保留完整目录结构。
4. 双击 **app/DesktopTodo.exe**。

程序以普通用户权限运行。首次运行默认注册当前用户的开机启动项；可在右键 → 设置中关闭。发布版启动项名称为 `DesktopTodo.Public`。

当前程序未签名。SHA-256 可以核对下载文件是否与发布者提供的文件一致，不能代替发布者身份验证或安全审计。

## 日常操作

| 想做什么 | 操作 |
|---|---|
| 新增、编辑任务 | 右键空白处或任务，选择相应操作 |
| 安排未来几天或整月 | 右键 → 编辑全部计划 |
| 调整顺序 | 按住任务任意位置上下拖动，在同一天、同一完成状态内插入 |
| 完成任务 | 向右拖过任务行宽度 60% 且至少 140 DIP 后松手 |
| 取消拖动 | 按 Esc；失焦或丢失鼠标捕获也会取消 |
| 恢复未完成 | 右键已完成任务 → 恢复未完成 |
| 设置截止时间与提醒 | 编辑任务 → 高级选项 |
| 移动窗口 | 拖动顶部空白区域 |
| 收起／退出 | 右键或托盘菜单；收起后提醒继续运行 |

单击和双击不会完成任务。编辑单条任务时，Enter 保存、Esc 取消尚未提交的修改；切换到其他窗口会保存有效内容，已保存的内容不会被后续取消撤销。

## 提前安排整月计划

在 **编辑全部计划** 中，上方填写月目标，下方连续编辑每天的任务。同一天可以添加多条；切换月份保留草稿，点击 **保存全部** 后统一写入。

使用 **粘贴多日计划** 时，日期单独一行，下面每行一项任务：

```text
2026-11-03
1. 整理资料
2. 核对记录

2026-11-04
1. 完成图表
```

支持完整日期、中文月日及“今天／明天／后天”。相对日期按电脑当天日期计算；仅写月日时使用当前编辑年份。导入先进入草稿，不直接覆盖现有任务。删除原有任务会在保存前确认。

## 从终端打开

在解压后的根目录运行一次：

```powershell
.\enable-command.ps1
```

关闭并重新打开终端后，从任意目录输入：

```text
todo
```

程序已运行时会唤回已有窗口。注册脚本只修改当前用户 PATH；遇到其他 `todo` 命令会停止，不覆盖。若机器的脚本执行策略阻止运行，可继续双击程序使用；按所在组织的脚本管理规则处理，不需要为了运行主程序降低安全设置。

## 数据、更新与移除

- `data/todo.db`：任务、月计划、设置和提醒状态，**未加密**。
- `data/backups`：每日首次启动创建备份，保留最近 7 份按日期命名的备份。
- `data/error.log`：出错时产生的本地日志。
- 应用在正常使用时不访问网络。下载、构建、依赖审计和 GitHub Actions 需要网络；Windows 自身服务独立于本应用。

更新前通过托盘彻底退出，备份 `data`，再覆盖程序文件并保留 `data`。移动整个目录后，手动运行一次可更新开机入口；已注册的命令 PATH 需要相应调整。

移除程序前关闭“开机自动展开”并退出；若注册过命令，从用户 PATH 移除该副本的 `bin` 路径。保留需要的 `data` 备份后再删除目录。

关机、睡眠或彻底退出期间不响铃、不唤醒电脑；恢复后补提醒。已关闭的提醒不反复弹出，关闭提醒不等于完成任务。系统静音或音频设备设置会影响提示音。

## 从源码构建

需要 Windows 和 `global.json` 指定的 .NET SDK（当前为 10.0.403）。可以安装该 SDK，或将 SDK 安装到项目内：

```powershell
.\setup-sdk.ps1
.\build.ps1
.\release.ps1
```

- `build.ps1`：执行核心检查，构建到 `app`。先退出正在使用该目录的应用。
- `release.ps1`：在独立暂存目录构建 ZIP 和 SHA-256，不覆盖已有运行目录。
- `artifacts/releases`：发布产物；不包含个人任务数据库、SDK 或本机快捷方式。
- 编译器和依赖缓存位于项目内 `.tools`。

主分支和 PR 配置了 Windows 构建流程；版本标签生成 Release **草稿**。远端流水线尚未实际运行验证。详见 [发布流程](docs/PUBLISHING.md)。
